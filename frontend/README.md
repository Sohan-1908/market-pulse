# Market Pulse ⚡
> Autonomous market intelligence, grounded in live data and compiled by autonomous AI agents.

## 🚀 Overview
**Market Pulse** is an elite, enterprise-grade SaaS market research platform designed to automate deep-dive industry analysis. It orchestrates a multi-agent AI pipeline to scrape verified live sources, cross-check facts, execute rigorous gap analysis, and generate executive-ready PDF dossiers with zero fabricated metrics.

## ✨ Core Features
- **Multi-Agent Execution Pipeline**: Sequential autonomous orchestration covering *Researcher*, *Analyst*, *Writer*, and *Complete* stages with real-time UI tracking.
- **Strict Citation Grounding**: Inline URL mapping and gap analysis ensuring zero hallucinated data or fabricated figures.
- **Persistent Storage**: Fully integrated with **Supabase** for lightning-fast report history and chat persistence.
- **Enterprise-Tier Aesthetic**: A clean, distraction-free obsidian/slate dark mode interface inspired by modern tools like Linear and Vercel.
- **Automated PDF Export**: Instantly compiles research findings into downloadable, structured executive dossiers.

## 🛠️ Tech Stack
- **Frontend**: Next.js (App Router), Tailwind CSS, TypeScript
- **Backend**: Python, FastAPI, Uvicorn, LiteLLM
- **Database & Auth**: Supabase (PostgreSQL with Row Level Security)
